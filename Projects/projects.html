Gamified Web-based Portfolio Tracker

A full-stack web app for tracking investments and savings with institutional-grade risk analytics (Beta, Sharpe Ratio, Variance) and a gamification layer that rewards good portfolio behaviour with XP, ranks, and achievements. Built with Node.js, PostgreSQL, and real-time market data from the Financial Modeling Prep API.

  • Node.js

  • jQuery

Warehouse operatives at Micheldever had no reliable way to track short stock, causing loading delays. I built a full-stack web app so stock operatives could post shortages in real time. This gave loading teams instant visibility and reduced unnecessary delays
